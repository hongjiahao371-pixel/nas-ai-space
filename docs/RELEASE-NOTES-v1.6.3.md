# NAS AI Space v1.6.3

This release completes the video moment and Jarvis API update, preserves successful visual indexing when optional audio fails, and distinguishes terminal source failures from queued work. A single-file retry lets an administrator refresh only the reviewed media. Audio timestamps now reflect the decoded length.

Ordinary search uses existing indexes. Boundary refinement is optional and sampled; it does not automatically verify counts, screenshot text or complete action order. Recovery archives exclude source media and uploads. Jarvis tool registration and independent audio quality require separate end-to-end acceptance.
