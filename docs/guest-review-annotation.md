# 外部审阅圈改

外链访客在有“允许评论”的分享中，可对已公开版本的图片或视频圈改。

1. 打开外链并按要求输入访问码。视频先播放到需要反馈的画面。
2. 点“画笔圈改”。视频会暂停并锁定当前时间，图片直接画。
3. 用鼠标或触屏在画面上画线，可撤销一笔、清空或取消。
4. 填写名字和审阅意见，再发布。没有发布不会保存；接口失败保留草稿。
5. 通过“查看圈改”回看对应版本与时间。需先切换到按钮标明的版本。
   团队审阅页点击这条意见也会暂停在对应时间显示圈改；播放时隐藏。

绘制期间切换版本须先发布或取消，防止笔画绑定错误版本。坐标相对于实际
媒体画面归一化，不包含播放器黑边，窗口缩放后仍对齐。音频、PDF 和其他
文件不提供画笔。没有评论权限的分享仍可回看已有的外部可见圈改。

## 边界与兼容性

- 复用 `review_comments.drawing_json`、`time_start`、`version_id` 和
  `comment_type`，没有 SQL 迁移、原媒体写入或新权限。
- 老评论继续读取。原有内部画笔保留其绘制行为，新的访客圈改采用单条、
  按时间的独立图层。回退程序不会删除已保存圈改，但旧外链 UI 不显示画笔。
- 服务端再次验证分享有效期、访问码、评论权限、素材范围和公开版本；
  团队内部意见不会返回外链。评论结果也使用公开字段白名单。
- 坐标必须有限且在 0–1 内；至多 32 笔、每笔 256 点、合计 2048 点。
  仅接受六位十六进制颜色；请求体最多 160 KiB。视频圈改必须绑定有效
  时间点和已分享版本，图片不接受时间点。
- 无法获取视频帧时需先播放再圈改，避免在没有实际画面的黑框上作画。

## 验证

```sh
python -m unittest discover -s tests -p 'test_guest_annotations.py' -v
node --check app/static/app.js
node --check app/static/guest-annotations.js
# optional dev dependency: Playwright Python and Chromium
python scripts/tests/guest_annotations_browser.py
```

浏览器回归使用合成图片，不连接 NAS。完整部署验收还应检查视频播放、
暂停/跳转/圈改/发布/刷新、不同宽高比和窗口缩放、移动触屏、重复发布、
附件上传失败，以及团队审阅对应时间的回看。生产验收仅使用专门的测试素材。
