# 素材篮：跨目录选材 → 项目交接

登录个人账号后，在素材库或搜索结果的网格、列表、检查器点击「+ 素材篮」。
切换目录、搜索词、页面或刷新后选择仍保留；重复加入自动去重。顶部「素材篮」
入口显示当前账号的数量，最多 200 项。

打开素材篮可复查可用性、预览、移除或清空。清空只删除选中记录，不删除原文件。
源文件离线、已删除或权限撤销后，该项只显示不可用，不回显之前的名称和路径。

选好具有编辑权限的项目，点击「加入所选项目」。这会在项目中创建原文件引用，
项目成员按现有项目权限访问这些资产，因此交接前应核对目标项目。重复点击不会
再次创建同一文件的资产；如果项目的任一版本已引用该文件，也跳过。若有任何
不可用素材，整个交接失败，不会只导入一半。交接成功后可进入项目，继续使用
已有版本、审阅、分享与后续剪辑导出链路。素材篮保留供下次使用。

## 安全和存储
- 需要真实用户账号；公共访客、系统 API Token、集成密钥不能拥有个人素材篮。
- 每个用户单独保存，服务器每次读取/加入/交接均验证当前文件访问范围。
- 仅新增 `material_basket_items` SQLite 表，不迁移/覆盖旧数据。
  表仅存用户 ID 和文件 ID，不保存文件名、路径或媒体副本。
- 前端不把素材信息写入 localStorage；切换账号立即清空界面状态，忽略旧请求结果。
- 项目权限和文件范围在交接事务内再次检查；新增资产与版本复用现有建资产逻辑，
  SQLite 写事务串行化并发提交，防止重复交接。
- 回滚程序不破坏原数据，新增表可以保留；旧版本不会显示素材篮。

## 验证
`python -m unittest discover -s tests -p 'test_material_basket.py' -v`

可选浏览器回归：`python scripts/tests/material_basket_browser.py`，需 Playwright
与 Chromium，仅使用合成 API 数据，不连接 NAS。实际 UI 验收需要确认两目录/
两次搜索选材、刷新保留、不可用项提示、交接及重复交接、账号隔离、手机宽度。
