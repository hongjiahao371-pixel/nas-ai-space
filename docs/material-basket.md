# 素材篮：跨目录选材 → 项目交接

登录个人账号后，在素材库或搜索结果的网格、列表、检查器点击「+ 素材篮」。
切换目录、搜索词、页面或刷新后选择仍保留；重复加入自动去重。顶部「素材篮」
入口显示当前账号的数量，最多 200 项。

打开素材篮可复查可用性、预览、移除或清空。清空只删除选中记录，不删除原文件。
源文件离线、已删除或权限撤销后，该项只显示不可用，不回显之前的名称和路径。

选好具有编辑权限的项目，点击「加入所选项目」。这会在项目中创建原文件引用，
项目成员按现有项目权限访问这些资产，因此交接前应核对目标项目。重复点击不会
再次创建同一文件的资产；如果项目的任一版本已引用该文件，也跳过。若有任何
不可用素材，整个交接失败，不会只导入一半。交接成功后可进入项目，继续使用
已有版本、审阅、分享与后续剪辑导出链路。素材篮保留供下次使用。

## 安全和存储
- 需要真实用户账号；公共访客、系统 API Token、集成密钥不能拥有个人素材篮。
- 每个用户单独保存，服务器每次读取/加入/交接均验证当前文件访问范围。
- 仅新增 `material_basket_items` SQLite 表，不迁移/覆盖旧数据。
  表仅存用户 ID 和文件 ID，不保存文件名、路径或媒体副本。
- 前端不把素材信息写入 localStorage；切换账号立即清空界面状态，忽略旧请求结果。
- 项目权限和文件范围在交接事务内再次检查；新增资产与版本复用现有建资产逻辑，
  SQLite 写事务串行化并发提交，防止重复交接。
- 回滚程序不破坏原数据，新增表可以保留；旧版本不会显示素材篮。

## 选片入出点与顺序（第二阶段）

视频搜索命中或素材卡点击「选片 / 导出」，检查开始与结束秒数，点「保存入出点
到选片篮」。同一视频可保存不同片段；相同入出点重复保存自动去重。入出点以
秒保存，服务端统一到微秒精度，不能越过已知视频时长，未知时长需先完成索引。

素材篮的选片区支持编辑/保存/取消入出点和上下移动，排序也保存在当前账号。
未保存的修改会禁用交接，避免误用旧入出点。普通整文件列表与有序片段列表
各自显示，两者合计最多 200 项；清空会同时清除两类选中记录。

交接到项目后点「将 N 段按当前顺序带入粗剪」：现有粗剪窗口会直接预填
精确项目版本、入出点及顺序。同一视频的多段指向同一正确版本，不重复创建
素材资产。剪辑电脑文件路径必须自行填写，不会读取或填入服务器私有路径。
后续导出仍走既有 FCPXML/manifest 验证链路。

新增独立 `material_basket_clips` 表，不重建旧素材篮表；旧整文件 API 返回保持
兼容，新增加 `clips`/`clip_total`/`combined_total`。失效片段只保留自己的选择
标识及入出点，不泄露旧名称/路径。交接前重新检查权限与时长，失败整批回滚。

每个已保存片段还绑定选片时源文件的 `mtime_ns + size`。仅修改标题、描述等
元数据不影响选择；文件替换或重扫后任一源修订值改变，片段会失效，编辑/
重复添加/交接都拒绝静默重绑定，必须移除后重新核对。旧表升级新增可空字段，
既有无修订记录的片段按失效处理，不自动匹配当前文件。交接给粗剪时携带
字符串修订标识，避免 JavaScript 大整数精度丢失；导出前再次校验，防止交接
后文件又被替换。未从选片篮创建的手动粗剪仍使用原有当前源校验。
