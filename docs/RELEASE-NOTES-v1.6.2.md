# NAS AI Space v1.6.2

视频详情新增“细查首尾与候选”：复用至多6个已索引候选，并补读至多2个视频首尾实际画面，再按查询与画面向量的相似度排列供核对。它不会改写索引或原始视频，仍属于有限抽样，不能保证按钮数量、文字或动作先后识别正确。

新处理的视频增加有界首尾采样；已有有效索引继续可用，不会自动全库重建。PCM音轨在送入模型前检查格式、帧数和完整性。可选音轨失败时保留成功的画面向量，并在状态中列出部分覆盖警告，不能把画面成功当作音轨也已验证。

读取不完整的图片继续标记失败，并提示从可靠备份恢复后重试。系统不会重写原图、忽略缺失数据或伪造成功。

普通素材搜索不增加按需细查的模型请求。新接口延续媒体库权限、版本校验、解码限制与内存缓存上限；繁忙请求可重试。

向量快照创建等待上限调整为300秒；下载完成后才原子发布本地快照，下载失败不清理服务器端快照或过期已有有效备份。同代素材重试会在成功发布后清理本文件多余的旧片段点，原Qwen集合保持原状。

本地、NAS隔离和真实样本验证状态记录见 PROGRESS.md。独立音频质量及全库检索效果仍待验收。
