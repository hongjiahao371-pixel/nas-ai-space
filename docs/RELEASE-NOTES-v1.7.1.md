# NAS AI Space v1.7.1

优化已有素材查询在磁盘繁忙时的等待。交互请求不再提交 SQLite 临时租约，使用应用与索引器共享的文件锁；无需修改备份任务优先级。已有数据库、模型和两套向量索引继续使用，无需重新索引。

素材优先模式同时读取文字与素材候选，随后按原顺序合并排序。最多四个并行读取任务，饱和时回到串行路径。模型推理期间不会阻塞已缓存的查询向量。接口增加 `timings_ms`，不包含查询文字或凭据。

验证包括数据库写锁争用、跨进程锁释放、并行失败与饱和回退、权限和过期素材过滤；生产实测与性能边界见 PROGRESS.md。该改动减少应用自行引入的等待，不能保证磁盘持续饱和、模型未加载或外部服务不可用时的固定响应上限。

备份校验按块读取向量快照并核对完整 SHA-256，数据库在备份目录内使用独立临时位置校验后删除，避免恢复包大于容器内存临时盘时失败。同盘快照暂存使用硬链接，跨盘自动回退复制，不降低备份校验或持久化要求。

新增独立文字查询进程，复用同一 EmbeddingGemma 2 权重，保留原向量维度、查询前缀和素材索引；模型权重常驻内存，查询进程限制为 768 MiB，视频和音轨仍由原进程处理。超长文字保留原通道。素材方案增加一个内部服务，不新增宿主端口。

为素材类型、媒体库和文件编号添加筛选索引，避免每次按范围检索时读取全部素材属性；不重算或替换向量。启动时补齐，已有兼容索引直接复用，不兼容类型保留并记录错误。
