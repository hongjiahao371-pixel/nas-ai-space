# v1.7.0 普通用户安装与维护

- 浏览器安装向导：选择NAS资料目录、检索方案和端口，自动准备容器和模型，显示下载进度与可重试状态。
- 完整素材检索进入公共安装流程；独立运行镜像自动下载并校验固定版本的模型和运行文件，不依赖旧NAS私有镜像。
- 应用内点选已授权文件夹，不再要求日常用户填写容器内路径。
- Git和压缩包安装使用同一套正式版更新流程；校验、升级前备份、程序回退。
- 完整素材方案从协调恢复包恢复到新数据目录和新向量卷，保留恢复前数据。
- 原始媒体仍由NAS备份保护。CPU与Intel x86-64为本轮验收目标；其他硬件不因配置存在而自动成为已验收平台。

本轮现场结果见 ACCEPTANCE-v1.7.0.md；未完成的验证不得写作通过。
