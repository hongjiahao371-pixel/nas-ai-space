# 架构说明

## 数据流

```text
只读媒体目录
  → 快速增量扫描
  → 分批/夜间深度索引调度
  → 类型解析
      ├─ 文档：按页/工作表提取、扫描 PDF 本地 OCR 与来源标记
      ├─ 图片：EXIF、缩略图、VLM 描述/OCR
      ├─ 视频：FFprobe、硬件抽帧、VLM、Whisper
      └─ 音频：FFprobe、Whisper
 → SQLite 元数据/全文索引与分阶段状态
  → OpenCV YuNet/SFace 人脸检测、特征与人物分组
  → GPS 地点聚类与时间/空间事件聚类
  → Embedding 批处理
  → Qdrant HNSW
  → 快速混合检索 → 可选首屏精准重排
  → 生产力编排层
      ├─ 知识空间 / 项目 / 指定文件范围
      ├─ 带页码/时间点来源的多轮问答
      ├─ 白名单文件 Agent：计划、确认、执行、审计、撤销
      ├─ 手动 / 文件到达 / 定时自动化
      └─ 带来源、版本和落盘文件的工作成果
```

FastAPI 进程只运行一个 Web worker，避免多个 worker 各自启动任务调度器。文件解析由内部受控线程池完成，任务状态和夜间索引策略持久化到 SQLite；服务重启时，运行中的任务会恢复为待处理状态。索引线程在处理每个文件前检查可用内存，低于保护线时等待，不继续扩大 Swap。

每个文件分别记录元数据、视觉、语音和向量阶段。上游模型临时失败时保留已经成功的内容并进入 `partial`，修复任务只选择错误、缺失或被阻塞的文件。失败会记录累计次数、最后尝试时间、错误指纹和下一次重试时间；指数退避期间不进入修复队列，达到上限后标记为终止错误，直到管理员明确手动重建。搜索完成度使用实际内容块和向量覆盖，不把只有元数据的文件标记为语义可检索。

任务表保存工作总量、已完成量和心跳时间。最近完成批次用于估算实际吞吐和剩余时间；服务启动会恢复中断任务并按保留策略清理历史终态任务。外部 NAS 编排器通过受保护状态接口上报运行、资源回收、等待、完成或降级状态，前端不再根据单次页面加载猜测索引进度。

## 生产力执行模型

知识空间只保存文件关系，不复制原文件。范围化问答与成果生成仍经过媒体库权限过滤；项目空间可以被项目成员复用，但写操作要求 owner、manager 或 editor 权限。

Agent 计划只接受四类结构化动作：`tag`、`copy_to_output`、`add_to_space` 和 `generate_artifact`。计划保存后处于 `draft`，用户必须输入任务专属确认文本才能进入持久化队列。Worker 真正执行前会再次检查账号启用状态、媒体库授权、项目编辑角色和知识空间权限，防止“确认后、执行前”权限变化造成越权。

每个 Agent 动作独立记录输入、状态、结果和错误。可逆信息在动作成功后立即持久化：标签恢复旧集合；知识空间只移除本次新增关系；复制成果记录大小和 SHA-256，文件被用户修改后拒绝自动删除；生成成果撤销时同时清理数据库版本与成果目录文件。应用不提供任意 Shell 或路径写入能力，复制目标只能是成果根目录下的规范化相对路径。

自动化使用“触发器 → 条件 → 动作”模型，并复用同一 Agent 执行器。文件到达触发会过滤账号媒体库权限和成果目录，避免输出再次触发自身；定时触发按分钟键去重且必须指定项目或知识空间。自动化先持久化关联 Agent ID，再开始执行，因此服务重启后可以继续已确认动作，无法证明是否完成的中途写入则转为失败并要求人工检查。

成果以 Markdown 为第一种交付格式。数据库保存每版提示、正文、来源和落盘路径，文件通过临时文件原子替换后再与版本记录一并提交；同一成果串行生成，防止并发版本号冲突。资料正文只作为证据，模型提示明确禁止执行资料内嵌的指令。

## 安全边界

- 日常扫描、预览和 AI 索引只访问媒体目录的只读挂载。
- 新媒体库必须位于 `NAS_AI_SCAN_ROOT` 内。
- API Token 保留为系统管理员钥匙；本地账号密码使用 scrypt（运行时不支持时回退 PBKDF2-HMAC-SHA256），会话令牌在数据库中只保存 SHA-256 摘要。
- 管理员可访问全部媒体库，普通成员只能搜索、浏览与预览被授权媒体库；上传也要求“上传空间”权限。
- 本地账号登录使用 HttpOnly、SameSite=Strict Cookie；写操作同时校验 CSRF Cookie 与请求头，Cookie 模式的登录响应不返回会话令牌正文。API Token 仍只为运维客户端保留在当前 origin 的 localStorage。
- URL 查询参数令牌默认不被 API 接受；兼容入口只负责清理遗留参数，不会把本地账号会话暴露给 JavaScript。
- 登录失败按客户端与用户名组合限流，API 响应包含 CSP、禁止 MIME 嗅探、同源 frame 限制和请求追踪 ID。
- 模型地址默认只允许解析到环回或私有 IP；只有显式开启 `NAS_AI_ALLOW_CLOUD_ENDPOINTS` 才允许公网端点。
- 应用容器丢弃 Linux capabilities、启用 `no-new-privileges`，根文件系统只读。
- 管理员回收重复副本前必须通过完整内容哈希确认另有未选中的保留副本。
- 精简 NAS Compose 的 `/maintenance/*` 是独立可写挂载，仅用于回收与恢复；普通媒体接口不会返回或使用该路径。
- 上传文件写入独立的 `/uploads`，回收文件写入独立的 `/recycle`。
- Agent 复制和 AI 生成只写入 `/uploads/AI 工作成果`；该目录不会触发文件到达自动化。
- 停用账号后，其尚未执行的 Agent 与自动化会在执行前被拒绝。

## 存储

- `./data/nas-ai-space.db`：SQLite 元数据、全文索引、任务、时间轴文本。
- `./data/cache`：可再生缩略图。
- `./data/backups`：自动创建 SQLite 在线备份，默认每 24 小时执行并最多保留 7 份。
- `./data/vector-backups`：最多保留 3 份下载到应用数据目录的 Qdrant 集合快照。
- `${NAS_UPLOAD_PATH}`：受控上传文件，与原媒体库隔离。
- `${NAS_UPLOAD_PATH}/AI 工作成果`：Agent 复制文件和版本化 Markdown 成果。
- `${NAS_RECYCLE_PATH}`：可恢复回收文件，与原媒体库隔离。
- `qdrant-data`：向量与 HNSW 索引。
- `ollama-models` / `openvino-*-models`：模型文件。
- `speech-models`：Whisper 模型缓存。
- 镜像内 `models/face_*.onnx`：官方 OpenCV Zoo YuNet/SFace 模型。
