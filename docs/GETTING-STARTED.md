# 第一次使用 AI Space

## 安装前准备

需要 x86-64 NAS 或 Linux 主机，先安装 Docker、Docker Compose v2 和 Python 3。建议 12–16 GB 内存和至少 15 GB 空间。8 GB 设备可选轻量文字方案。ARM 设备尚未验收。

从项目首页的“普通用户安装”运行一次安装入口，打开终端显示的临时链接。选择资料所在的文件夹和检索方案，再点“开始安装”。无需填写模型地址、下载模型文件或编辑配置。

首次下载耗时取决于网络。页面显示下载进度时请保留终端，下载失败可点“继续启动 / 重试下载”。安装过程只读取你选定的资料，不会搬走原文件。上传的文件与 AI 成果会单独保存。

## 从零到第一次搜索

1. 点击“打开 AI Space”，创建管理员用户名和密码。这是日常登录账号，请使用密码管理器保存。
2. 首页点“连接资料目录”，打开“资料文件夹”，点选需要的子文件夹，再点“使用当前文件夹”。填写容易记住的名称并添加。
3. 点“快速扫描”。扫描后可以按文件名找资料，AI 尚未分析完的文件会继续显示准备状态。
4. 点“建立 AI 索引”，在任务页启动一批资料的分析。完整方案还会自动准备图片、视频和采样音轨的素材索引。
5. 用首页搜索框输入一句自然语言，例如“红色的圆形图案”或一份文档中的主题。打开结果查看原文、画面或时间点。

安装完成与资料全部分析完成是两回事。少量损坏或不受支持的文件会单独显示错误，不会悄悄计入完成率。视频时间点是候选位置，需要打开画面核对。

## 让其他人使用

在“用户管理”创建成员账号，为他选择能访问的媒体库，再给他应用地址和初始密码。不要把管理员账号、系统令牌或临时安装链接分享出去。成员只能搜索授权的资料；管理员才可以添加 NAS 目录或维护系统。

同一局域网可直接访问；外出使用需要 VPN，或由管理员配置 HTTPS 入口。AI Space 不会自动把 NAS 开放到公网。

## 以后维护

在安装目录运行 `scripts/nas-ai wizard`，重新打开临时维护页。

- **升级**：点“检查并升级正式版”。系统校验官方安装包，先备份后升级；失败时尝试回到旧程序。
- **切换方案**：展开“更换检索方案”。从轻量方案开启完整素材检索会追加下载模型，账号和已有索引保留。
- **备份**：点“立即备份”。完整素材方案包含数据库和两个索引；原始资料、上传文件和模型请同时使用 NAS 备份保护。
- **恢复**：选已有备份，输入“恢复”。完整恢复包会写入新位置，保留恢复前的数据。
- **程序回退**：适用于本次升级后程序不正常，不会把数据库恢复到过去。需要恢复历史资料状态时请选择备份恢复。
- **卸载后重装**：`scripts/nas-ai uninstall` 保留资料、账号和模型。之后运行 `scripts/nas-ai start` 重新启动。

## 卡住时先看这里

| 情况 | 处理方法 |
| --- | --- |
| 找不到 Python 或 Docker | 在 NAS 应用中心安装相应组件，并确认 Docker 服务已启动 |
| 提示 Docker 无权限 | 按终端提示完成一次管理员授权，或由 NAS 管理员给当前账号 Docker 权限 |
| 端口被占用 | 返回安装页选择另一个端口 |
| 模型下载失败 | 检查 NAS 到 GitHub、模型站和容器仓库的网络，恢复后点“继续启动”；已下载部分会保留 |
| 点选文件夹后无权限 | 在 NAS 文件管理器授权当前安装账号读取资料，不要把整个目录改成人人可写 |
| 搜索只有文件名结果 | 查看 AI 索引任务与素材覆盖状态，等待分析完成或按提示重试失败文件 |
| 老版没有维护向导 | 按 README 的旧版升级入口，在原安装目录升级；不要在原目录运行新安装 |

支持范围、完整恢复边界和本版本实测结果见 [验收记录](ACCEPTANCE-v1.7.0.md)。
