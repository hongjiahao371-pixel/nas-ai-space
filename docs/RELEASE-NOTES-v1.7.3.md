# NAS AI Space v1.7.3

v1.7.3 为 ARM64 Linux 增加 CPU 安装支持。安装向导、账号、文件夹授权、检索、备份与维护入口沿用现有流程；现有 x86-64 用户无需为 ARM 适配重新安装。

- 应用和素材服务提供 linux/amd64 与 linux/arm64 镜像，由 Docker 自动选择。
- 素材运行程序仍使用固定的 llama.cpp b11480 和原有 EmbeddingGemma 2 权重，按架构下载、校验并隔离运行缓存。
- ARM64 默认选择 CPU；旧的仅 x86 发布包及 32 位 ARM 会在安装前明确阻止。ARM NPU/GPU、Jetson CUDA 和各厂商应用商店安装包不在本版范围。
- 新增原生双架构容器验证，含默认 Qwen 文字向量与看图模型实际推理；覆盖范围与证据见 [ARM64 验证记录](ACCEPTANCE-v1.7.3.md)。

建议 12–16 GB 内存和至少 15 GB 空间；8 GB 设备可选轻量文字方案。原生 ARM Linux 验证不代表每款 NAS 的整机兼容性或性能验收。升级保留原配置、媒体和索引；既有 x86-64 NAS 的 v1.7.2 备份并行性能验收不能自动套用到 ARM。

本轮不包含 ARM 设备的语音转录、视频语义质量、成员权限端到端场景或完整升级/备份恢复生命周期复测；对应自动化回归保留，不能替代这些专项实机验收。
