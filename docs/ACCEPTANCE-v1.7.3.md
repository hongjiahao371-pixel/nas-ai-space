## 支持与验证边界

- 支持范围为 64 位 Linux CPU：amd64 和 arm64。ARM64 安装默认选择 CPU；32 位 ARM、ARM NPU/GPU 与 Jetson CUDA 不在此版范围。
- 这是原生 ARM Linux 环境验证，不是每一款 ARM NAS 的整机验收，不承诺低端设备或 8 GB 机器的处理速度。建议先用少量资料核对性能。
- 本轮没有重新完成 ARM 上的整套网页安装、升级回退、备份恢复、成员权限端到端流程，也没有 ARM 语音转录或视频语义质量验收。既有自动化回归与 x86-64 历史实机验收保持独立，不能替代这些边界。
- v1.7.2 的生产 NAS 和完整备份并行性能验收不变；此任务没有更新或重启生产 NAS，不把 x86-64 的延迟成绩套用到 ARM。

每次原生任务保存 `native-runtime-amd64` / `native-runtime-arm64` 证据，包括版本/架构、模型摘要、实际接口结果、服务日志与清理结果。发布时比对已测和待发布镜像的配置摘要，两种架构都成功后才生成公共镜像清单和发布包。
