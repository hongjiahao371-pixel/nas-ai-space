# NAS AI Space 网页摘录（本地原型）

普通 Chromium 网页上选中一段文字，再打开扩展，主动读取选区。检查并可编辑标题、来源及文字，点「保存到本地」。**第二步**到 NAS AI Space 目标项目的入库箱，选择 `.nas-capture.json` 并确认导入。不是全程一键保存；插件不会连接 NAS。

仅通过 `activeTab` 和 `scripting` 在用户点击时读取主页面的选区。通常不会读取表单、可编辑区域、嵌套页面或受浏览器保护的页面；不读取 HTML、图片、Cookie，也不采集整个网页。只保存你预览的纯文本及来源信息。查询参数和片段会移除，路径和摘录仍可能有隐私内容，请在导出、导入共享项目之前各自检查。标题、来源等可手工修改，来源与时间不是第三方验证的事实。不要采集无权分享的内容。

本地开发时，可在专用测试浏览器的扩展管理界面手动载入本目录，使用合成页面测试；未发布扩展商店，不需要 API 密钥或长期主机访问。点击保存只请求浏览器下载，以下载记录为准。

`node --test capture.test.mjs` 测试序列化、网址限制、身份字段、字数/字节上限和扩展权限；实际浏览器选区/下载行为须另验收。
